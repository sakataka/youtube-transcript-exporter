# YouTube AI Brief

公開されているYouTube動画の字幕または自動字幕を取得し、生成AIに渡しやすいプロンプト付きテキストへ整えるmacOS向けローカルGUIアプリです。動画タイトル、チャンネル名、公開日、動画時間などの補助情報も可能な範囲で付け、ChatGPTなどへ貼り付けて要約・解説・画像生成に使える形にします。

## 主な機能

- YouTube URLから取得可能な手動字幕・自動字幕を確認できます。
- YouTube URLを入力欄に貼り付けると、自動で字幕候補を確認します。
- 字幕の言語と字幕種別を選んで、字幕本文を取得できます。
- 自動字幕で `en` と `en-orig` のように同じ内容になりやすい候補は1つにまとめて表示します。
- 取得した字幕は、動画情報と用途別プロンプトを付けてコピーできます。
- 取得後に `Codexに質問` を押すと、Codex App Serverをアプリ内の子プロセスとして起動し、同じプロンプトを渡して回答をMarkdown表示できます。
- AI回答はコピー、Markdown保存、再実行、追加質問、選択範囲での質問ができます。回答中の `12:34` のような時刻はYouTubeの該当箇所を開くリンクとして扱います。
- AI回答は直近20件までローカル履歴に保存され、後から復元できます。
- コピー用プロンプトは、概要、要点、詳細解説、主張と根拠、語学・学習向けの初期テンプレートから選べます。
- プロンプトテンプレートはアプリ内で追加・編集・削除でき、デフォルトも指定できます。
- コピー設定で、画像生成指示を含めるかどうかを切り替えられます。
- 自動字幕は、コピー前に段落化と空白整理を行う読みやすい整形を有効・無効にできます。手動字幕は原文を優先してそのまま扱います。
- 起動時は前回入力したURLを引き継がず、入力欄を空にします。
- UIは日本語をデフォルトとし、設定画面から英語に切り替えられます。

## 必要なもの

- Bun
- Rust
- yt-dlp
- Codex CLI（アプリ内でAI回答を生成する場合）

macOSで `yt-dlp` がない場合:

```sh
brew install yt-dlp
```

Codex連携を使う場合は、事前にCodex CLIへログインしておきます。アプリは `codex app-server` を別途常駐させず、`Codexに質問` ボタンを押したときに標準入出力の子プロセスとして起動します。

## 開発起動

```sh
bun install
bun run app
```

Tauriの開発ウィンドウが起動します。

## macOSアプリの作成

```sh
bun run package
```

生成された `.app` はFinderからダブルクリックして起動できます。Finder起動時も `yt-dlp` を見つけられるように、アプリ側で `PATH` に加えて `/opt/homebrew/bin/yt-dlp`、`/usr/local/bin/yt-dlp`、`/usr/bin/yt-dlp` を探索します。

ビルドした `.app` を `/Applications` にコピーして、すぐ使える状態にしたい場合:

```sh
bun run package:install
```

このコマンドはビルド後に `src-tauri/target/release/bundle/macos/YouTube AI Brief.app` を `/Applications` に上書きコピーします。コピー先を変える場合は `APPLICATIONS_DIR=/path/to/apps bun run package:install` を使います。旧名の `YouTube Transcript Exporter.app` が同じコピー先に残っている場合は削除します。

## 対応範囲

- 公開動画の字幕・自動字幕が取得できる場合のみ対応します。
- 取得可能な手動字幕・自動生成字幕を一覧表示し、言語と字幕種別を指定して取得できます。
- 自動字幕の同一基準言語候補は、元字幕に近い候補を優先して1つにまとめます。手動字幕と自動字幕は内容が異なる可能性があるため別候補として扱います。
- 字幕を指定しないAPI利用では、日本語字幕を優先し、なければ英語、それもなければ取得可能な最初の字幕を使います。
- 自動翻訳字幕は候補から除外します。
- 取得した本文は、用途別の日本語プロンプトと動画情報を付けてコピーできます。
- 取得済みの内容は、コピーせずにCodex App Serverへ直接渡し、文章回答をアプリ内の `AI回答` タブにMarkdownとして表示できます。画像生成指示が有効な場合は、文章回答後に同じスレッドで画像生成も依頼し、完了した画像を同じタブに表示します。
- Codex回答の生成中はキャンセルできます。完了した回答はコピー、Markdown保存、再実行、追加質問に使えます。
- 字幕本文またはAI回答の選択範囲だけをもとにCodexへ追加質問できます。追加質問は前回のAI回答や選択範囲を文脈として新しい質問を実行します。
- AI回答履歴はブラウザの `localStorage` に直近20件まで保存します。完全なアーカイブが必要な回答はMarkdown保存を使います。
- コピー用プロンプトはアプリ内で追加・編集でき、デフォルトも指定できます。
- コピー設定はローカルに保存され、次回起動時も前回の状態を使います。
- UIは設定画面から日本語・英語を切り替えられます。デフォルトは日本語です。
- 取得できる場合は、チャンネル名、公開日、動画時間もプロンプト内の動画情報に含めます。
- 画像生成指示を有効にした場合は、コピー用プロンプトの最後に動画内容を1枚の画像にまとめる依頼を追加します。
- 自動字幕整形を有効にした場合は、自動字幕のみ段落化と空白整理を行ってコピーします。
- 自動字幕の場合は、誤認識の可能性をプロンプト内で明示します。
- 入力欄へYouTube URLを貼り付けた場合は、確認ボタンを押さずに字幕候補の取得を始めます。
- 起動時の入力欄は常に空にし、前回のURLを自動入力しません。
- 音声認識、音声ダウンロード、ログインが必要な動画、年齢制限や地域制限の回避は行いません。
