# YouTube AI Brief

公開されているYouTube動画の字幕または自動字幕を取得し、生成AIに渡しやすいプロンプト付きテキストへ整えるローカルWebアプリです。ローカルで起動したWebサーバーが `yt-dlp` と Codex CLI を呼び出し、ブラウザUIから字幕取得、コピー、AI回答生成を行います。動画タイトル、チャンネル名、公開日、動画時間などの補助情報も可能な範囲で付け、ChatGPTなどへ貼り付けて要約・解説・画像生成に使える形にします。

フロントエンドは React、Tailwind CSS、shadcn/ui を基盤とし、キーボード操作可能なTabs、モーダルDialog、統一されたフォーム部品を使用します。配色はOSのライト・ダーク設定へ自動追従します。

## 主な機能

- YouTube URLから取得可能な手動字幕・自動字幕を確認できます。
- YouTube URLを入力欄に貼り付けると、自動で字幕候補を確認します。
- 字幕候補が1件だけの場合は、字幕本文を自動取得して、そのままAIへ質問します。
- 複数候補がある場合は、字幕の言語と字幕種別を選ぶと字幕本文を自動取得します。
- 動画タイトルとサムネイルを表示し、取得対象の動画を確認しやすくします。
- 自動字幕で `en` と `en-orig` のように同じ内容になりやすい候補は1つにまとめて表示します。
- 取得した字幕は、動画情報と用途別プロンプトを付けてコピーできます。
- `AIに聞く` を押すと、ローカルWebサーバーがCodex App Serverを子プロセスとして起動し、同じプロンプトを渡して回答をMarkdown表示できます。
- AI回答はコピー、再実行、追加質問、選択範囲での質問ができます。回答中の `12:34` のような時刻はYouTubeの該当箇所を開くリンクとして扱います。
- AI回答は直近20件までローカル履歴に保存され、後から復元できます。
- コピー用プロンプトは、概要、要点、詳細解説、主張と根拠、語学・学習向けの初期テンプレートから選べます。
- プロンプトテンプレートはアプリ内で追加・編集・削除でき、デフォルトも指定できます。
- 設定画面のコピー設定で、画像生成指示を含めるかどうか、自動字幕整形、字幕のタイムスタンプ表示を切り替えられます。
- 自動字幕は、コピー前に段落化と空白整理を行う読みやすい整形を有効・無効にできます。手動字幕は原文を優先してそのまま扱います。
- 起動時は前回入力したURLを引き継がず、入力欄を空にします。
- UIは日本語をデフォルトとし、設定画面から英語に切り替えられます。

## 必要なもの

- Bun
- Rust 1.96.1以降（Rust 2024 edition）
- yt-dlp
- Codex CLI（Webアプリ内でAI回答を生成する場合）

macOSで `yt-dlp` がない場合:

```sh
brew install yt-dlp
```

Codex連携を使う場合は、事前にCodex CLIへログインしておきます。ローカルWebサーバーは `codex app-server` を別途常駐させず、`Codexに質問` ボタンを押したときに標準入出力の子プロセスとして起動します。AI回答には `gpt-6-astra` を推論強度 `medium` で使用します。

## 開発起動

```sh
bun install
bun run web
```

ビルド後にローカルWebサーバーが起動します。表示された `http://127.0.0.1:5179` をブラウザで開きます。

すでに `dist/` を作成済みで、サーバーだけ起動したい場合:

```sh
bun run web:server
```

`PORT=5180 bun run web:server` のようにポートを変えられます。別ディレクトリのビルド成果物を使う場合は `WEB_DIST_DIR=/path/to/dist bun run web:server` を使います。

## 対応範囲

- 公開動画の字幕・自動字幕が取得できる場合のみ対応します。
- 取得可能な手動字幕・自動生成字幕を一覧表示し、言語と字幕種別を指定できます。字幕を選ぶと本文を自動取得します。
- 自動字幕の同一基準言語候補は、元字幕に近い候補を優先して1つにまとめます。手動字幕と自動字幕は内容が異なる可能性があるため別候補として扱います。
- 字幕を指定しないAPI利用では、日本語字幕を優先し、なければ英語、それもなければ取得可能な最初の字幕を使います。
- 自動翻訳字幕は候補から除外します。
- 取得した本文は、用途別の日本語プロンプトと動画情報を付けてコピーできます。
- 取得済みの内容は、コピーせずにCodex App Serverへ直接渡し、文章回答を `AI回答` タブにMarkdownとして表示できます。画像生成指示が有効な場合は、文章回答後に、元の動画情報・説明文・字幕全文と文章回答を画像生成メッセージへ明示的に再掲して画像生成を依頼し、完了した画像を同じタブに表示します。
- Codexへ渡すプロンプトには、全テンプレート共通でMarkdown形式の回答指示を追加します。個別テンプレート本文はそのまま保持されます。
- `AI回答` タブは読むためのMarkdownビューアとして表示し、見出し、箇条書き、引用、コード、リンク、画像を整形して表示します。
- `AI回答` タブ内の `mm:ss`、`h:mm:ss`、`3分20秒` のような時刻表記は、動画の該当時刻を開くYouTubeリンクとして表示します。
- Markdownビューアはアプリ共通のスタイルで表示し、回答コピーでは表示用CSSではなく元のMarkdown本文を扱います。
- Codex回答の生成中はキャンセルできます。完了した回答はコピー、再実行、追加質問に使えます。
- AI回答が完了したときは短い完了音を鳴らします。設定画面の `表示` タブからオフにできます。
- 生成AIへの依頼や応答が遅い場合の調整用に、`~/Library/Logs/YouTube AI Brief/debug.log` へJSON Lines形式のデバッグログを書き出します。設定画面の `表示` タブから、外部アプリを開かずにログ内容を確認できます。
- 字幕本文またはAI回答の選択範囲だけをもとにCodexへ追加質問できます。追加質問は前回のAI回答や選択範囲を文脈として新しい質問を実行します。
- AI回答履歴はブラウザの `localStorage` に直近20件まで保存します。
- コピー用プロンプトはアプリ内で追加・編集でき、デフォルトも指定できます。
- コピー設定は設定画面にまとまり、ローカルに保存され、次回起動時も前回の状態を使います。
- UIは設定画面から日本語・英語を切り替えられます。デフォルトは日本語です。
- 取得できる場合は、チャンネル名、公開日、動画時間もプロンプト内の動画情報に含めます。
- 画像生成指示を有効にした場合は、コピー用プロンプトの最後に、字幕を根拠として動画固有の論点、根拠、具体例、話の流れ、関係性、結論を高密度な1枚の日本語インフォグラフィックへ整理する依頼を追加します。
- 自動字幕整形を有効にした場合は、自動字幕のみ段落化と空白整理を行ってコピーします。
- 自動字幕の場合は、誤認識の可能性をプロンプト内で明示します。
- 入力欄へYouTube URLを貼り付けた場合は、確認ボタンを押さずに字幕候補の取得を始めます。候補が1件だけなら、字幕取得後にAI回答生成まで自動で進みます。
- 起動時の入力欄は常に空にし、前回のURLを自動入力しません。
- YouTube動画の音声認識、音声ダウンロード、ログインが必要な動画、年齢制限や地域制限の回避は行いません。
